# WebRTC 远程控制操作说明

云雀通 WebRTC 远控让你通过 iPhone、iPad，或者安卓手机、安卓平板，访问家里、办公室的 Windows 或 Mac 电脑，查看当前桌面并进行键鼠操作。

**使用前需要先完成云雀通组网，并保证 App 能通过该网络访问目标电脑。** 安装 WebRTC 服务端只是在电脑上提供远控服务，还需要 Larktun 网络把两端连起来。

本文覆盖两种连接方式：

- **直接组网远控**：目标电脑安装 Larktun 组网客户端和 WebRTC 服务端，App 使用电脑的云雀通地址连接。
- **子网远控**：通过已接入云雀通的子网路由节点访问内网，App 使用目标电脑的局域网 IP 连接；目标电脑仍需安装 WebRTC 服务端。

## 1. 下载前，先分清三个程序

打开 [Larktun 官网](https://larktun.com)，进入 [下载页面](https://larktun.com/download)，获取对应程序。

| 程序 | 安装在哪台设备 | 用途 |
| --- | --- | --- |
| 云雀通 App（iPhone / iPad / Android） | 发起远控的 iPhone、iPad，或安卓手机、平板 | 在 App 内连接云雀通网络，并打开 WebRTC 远控 |
| Larktun 组网客户端 | 目标 Windows / Mac，或负责转发子网的路由节点 | 让电脑或子网接入云雀通网络 |
| WebRTC 服务端（Larktun Host） | 每台需要被控制的 Windows / Mac | 传输桌面和声音，接收远程操作 |

在 iPhone/iPad 上，通过官网提供的 App Store 入口下载安装云雀通 App；安卓手机和平板从官网下载 Android 安装包，手机和平板使用同一个安装包，Android 版需要 0.2.0 或更高版本。电脑端从官网分别下载适合当前系统的 **Larktun 客户端**和 **WebRTC 服务端**，不要漏装其中一个。

:::tip[子网模式的安装区别]

直接组网时，目标电脑需要同时运行 Larktun 客户端和 WebRTC 服务端。

子网模式下，由路由节点运行 Larktun 并转发内网流量，目标电脑可以不安装 Larktun 客户端；但**每台要被控制的电脑都必须安装、运行 WebRTC 服务端**。只在路由节点安装 Host，不能代替其他电脑上的 Host。
:::

## 2. 先完成组网

首次使用建议先采用直接组网方式：

1. 在 Windows 或 Mac 上安装 Larktun 组网客户端，登录自己的云雀通账户并连接。
2. 在 iPhone、iPad 或安卓设备上打开云雀通 App，登录同一账户，接入同一个网络。
3. 确认电脑处于在线状态，记下它的云雀通 IP，例如 `100.64.0.10`。
4. 如配置了 ACL，确认当前账户或设备有访问目标电脑的权限。

电脑客户端的安装与登录可参考 [电脑客户端操作](./desktop-client-operations)，首次网络配置可参考 [快速开始](./quick-start)。

如果准备使用子网远控，先完成下面的 Host 安装，再按 [子网远控步骤](#5-使用局域网-ip-进行子网远控) 配置路由。

## 3. 安装并启动 WebRTC 服务端

### Windows

1. 从 [官网下载页](https://larktun.com/download) 获取 Windows WebRTC 服务端安装包，运行安装向导。
2. 按系统提示完成管理员授权。
3. 设置监听地址和访问令牌。默认监听地址为 `:8771`，默认远控连接端口为 `8771`。
4. 按需选择系统声音采集，保留所需的防火墙放行规则，然后完成安装。
5. 确认 `LarktunWebRTCHost` 服务正在运行。安装版以 Windows 服务运行，支持开机自启。

访问令牌由你设置，稍后需要在 App 的连接页面填写相同内容。建议使用不易猜测的令牌，不要将日常远控配置为免令牌访问。

### macOS

1. 从 [官网下载页](https://larktun.com/download) 获取 Mac WebRTC 服务端 `.pkg` 安装包并安装。
2. 打开菜单栏中的 **Larktun Host**，进入设置。
3. 配置监听地址、访问令牌，以及是否采集系统声音、是否登录时启动。
4. 在 **系统设置 → 隐私与安全性** 中，为 Larktun Host 允许 **屏幕录制**和 **辅助功能**。
5. 按 Host 提示重启应用，再点击 **保存并启动**，确认服务运行。

屏幕录制权限用于获取画面，辅助功能权限用于接收键鼠输入。只允许屏幕录制时，可能出现“能看见桌面，但无法操作”。

### 监听地址怎么填

| 场景 | 监听地址示例 | 说明 |
| --- | --- | --- |
| 默认配置 | `:8771` | 在本机可用网卡上监听，配合访问令牌和防火墙控制来源 |
| 只接受直接组网访问 | `100.64.0.10:8771` | 绑定本机实际的云雀通 IP |
| 只接受子网路径访问 | `192.168.6.10:8771` | 绑定目标电脑实际的局域网 IP，供子网路由节点访问 |

示例 IP 需要替换成电脑自己的地址。不要填 `127.0.0.1`，它只允许本机访问。子网模式下，也不能只绑定云雀通 IP 而忽略实际接入的局域网地址。

这些监听设置都不要求在公网路由器上做端口映射。保留目标电脑本机所需的防火墙规则，并将访问范围限制在需要的私有网络内。

## 4. 在手机或平板上发起连接

确认 App 已接入网络、Host 已运行后：

1. 打开 App 内的 **WebRTC 远控**入口；也可从目标设备的快捷操作进入。Android 上可以在设备详情或设备长按菜单中点 **WebRTC**，也可以从右上角“+”选择 **WebRTC 远控**；从设备进入时会自动填好主机地址。
2. 填写连接信息：

| 字段 | 直接组网示例 | 填写说明 |
| --- | --- | --- |
| 主机 | `100.64.0.10` | 目标电脑的云雀通 IP；不需要添加 `http://` 或端口 |
| 端口 | `8771` | Host 的实际监听端口 |
| Token | 你在 Host 中设置的令牌 | 必须与目标电脑一致；它不是云雀通登录密码，也不是组网 Auth Key |
| 名称 | `办公室电脑` | 可选，用于辨认收藏 |

3. 按需开启 **保存到收藏**，点击 **连接**。
4. 看到桌面后，测试点击、输入和声音，确认可正常使用。

收藏中的令牌在 iOS 上保存在系统 Keychain 中；在 Android 上用 Android Keystore 中的密钥加密后保存在本机。以后可以从收藏重新进入，不必反复填写。

:::note[端口与地址要分开]

主机填写 IP，端口填写 `8771`。不要把 `100.64.0.10:8771` 整段填进主机栏，也不要填写官网地址代替目标电脑 IP。
:::

## 5. 使用局域网 IP 进行子网远控

子网远控适合这样的环境：办公室里有多台电脑，你已经通过一台路由器、网关或 Linux 设备，把办公室局域网接入云雀通。

**子网访问打通后，知道目标电脑的局域网 IP，就可以在 WebRTC 远控页面填写该 IP 发起连接。** 目标电脑不必单独加入云雀通设备列表，但它必须运行 WebRTC 服务端，并允许来自子网路由节点的访问。

### 准备子网路由

以下面这组示例为例：

| 设备或网络 | 示例 |
| --- | --- |
| 办公室内网 | `192.168.6.0/24` |
| 子网路由节点 | 能访问上述网段、已登录 Larktun 并保持在线的设备 |
| 要远控的电脑 | `192.168.6.10`，已安装 WebRTC 服务端 |
| 控制端 | 已接入云雀通网络的 iPhone、iPad 或安卓手机、平板 |

先完成以下配置：

1. 让路由节点宣告目标子网，例如 `192.168.6.0/24`。
2. 在云雀通控制台批准该子网路由。
3. 配置 ACL，允许当前账户或设备访问目标子网中的远控服务。
4. 确认路由节点本身可以访问目标电脑，且转发配置正常。
5. 确认手机 App 已获得可用的子网访问路径。

路由宣告、批准、ACL 和转发配置的完整步骤见 [批准子网路由](./approve-subnet-routes)。手机和平板使用 App 内的组网能力，不需要在 iPhone、iPad 或安卓设备上执行该文档中的桌面 CLI 命令。

### 确认目标电脑上的服务

1. 在 `192.168.6.10` 这台电脑上安装、运行 WebRTC 服务端。
2. 设置访问令牌，确认 Host 在局域网地址上可访问，例如监听 `:8771` 或 `192.168.6.10:8771`。
3. 保持默认的内嵌中继配置，确保所需端口没有被 ACL 或本机防火墙阻断。

子网远控除了连接端口，还可能使用 Host 内嵌的媒体中继：

| 连接 | 默认值 | 用途 |
| --- | --- | --- |
| Host 连接端口 | TCP `8771` | 建立远控会话 |
| 子网媒体回退通道 | TCP `3478` | 通过 Host 内嵌 TURN 转发加密媒体，帮助建立子网远控 |
| 直接媒体路径 | ICE 使用的 UDP 端口 | 条件允许时用于直接传输；按 Host 程序设置所需防火墙权限 |

**只放行 `8771`，可能出现连接有响应，却一直停在协商阶段。** 排查子网连接时，同时确认默认 TCP `3478` 可达、Host 内嵌中继没有被禁用。使用默认安装配置时，App 会自动尝试相应路径，不需要另外购买或搭建公网 TURN 服务。

端口放行针对云雀通或所需内网路径，不需要映射到公网。如果自行修改了服务端中继端口，需要确认客户端配置能够匹配；初次使用建议保留默认值。

### 在 App 中填写子网 IP

打开 **WebRTC 远控**，填写：

| 字段 | 子网远控示例 |
| --- | --- |
| 主机 | `192.168.6.10` |
| 端口 | `8771` |
| Token | `192.168.6.10` 上 WebRTC 服务端的令牌 |

点击连接即可。**主机填要控制的电脑 IP，不是子网路由器的 IP。** 即使页面主机栏提示“tailnet IP”，这里也支持填写经云雀通子网路由可达的局域网 IP。

目标电脑的 IP 发生变化后，需要更新连接或收藏。长期使用可以在路由器中为电脑配置固定 DHCP 租约，便于持续访问。

## 6. 连接后的常用操作

- **触控与键盘**：用触控操作远程桌面，按需打开屏幕键盘和快捷键；iPad 可配合外接键盘、鼠标或触控板使用。Android 上可以在触控模式和鼠标模式之间切换，双指缩放画面，键盘上方的工具条提供 Ctrl、Alt、Shift、Win/⌘ 和 Ctrl+Alt+Del。
- **文本剪贴板**：复制、粘贴文本，在 App 和目标电脑间传递地址或命令。
- **画质设置**：根据带宽调整画质和帧率。移动网络下可先降低画质，再检查操作是否顺畅。
- **多屏切换**：目标电脑有多个显示器时，在菜单里选择当前查看的屏幕，一次显示一块。
- **系统声音**：需要听到远端播放声音时，确认 Host 已开启声音采集，并检查手机或平板的音量和输出设备。
- **多设备连接**：多台设备可同时连接同一电脑，一台控制，其余观看。新设备加入会获得控制权，观看端可点击 **接管控制**接手。
- **离开远控页面**：在 Android 上回到首页时，远控保持连接，首页顶部的会话入口可以随时回到画面；App 在系统后台超过 10 分钟后会自动断开。

多台设备看到的是同一个桌面。只向愿意共享桌面和控制权的设备提供访问权限与令牌。

## 7. 常见问题

| 现象 | 检查方法 |
| --- | --- |
| 安装 Host 后仍连不上 | 确认 App 已组网；直接模式下电脑 Larktun 客户端也要在线，子网模式下路由节点要在线 |
| App 设备列表能看到电脑，但远控失败 | 设备在线不等于 Host 运行；检查服务状态、实际监听地址、端口、Token、ACL 和防火墙 |
| 子网设备不在 App 设备列表 | 可以直接输入其局域网 IP；先确认子网路由已批准、权限允许、目标电脑 Host 正常 |
| 子网路由批准后仍无法连接 | 检查路由节点是否能访问目标 IP、是否正常转发，以及目标防火墙是否允许该路径 |
| 子网远控一直停在协商阶段 | 检查 TCP `8771` 和 `3478`、Host 内嵌中继状态；不要只凭 Ping 成功判断远控正常 |
| 提示令牌错误 | 填写目标电脑 Host 中配置的 Token；不要填云雀通账户密码或 Auth Key |
| Mac 没画面 | 检查屏幕录制权限，授权后按提示重启 Larktun Host |
| Mac 能看不能操作 | 检查辅助功能权限；多设备连接时也确认当前是否“仅观看” |
| 被另一台设备接管 | 在观看提示中点击“接管控制”；这是多设备共享桌面的控制权切换 |
| 外出后电脑失联 | 检查电脑供电、睡眠、Host 与 Larktun 自启动；子网模式还要检查路由节点在线状态 |

Mac 用户已登录后锁屏，可以通过远控尝试解锁；重启后尚未首次登录时，Host 无法采集登录画面。无人值守使用前，应在目标电脑上完成实际验证。

## 8. 第一次使用的验收清单

1. 确认手机或平板上的云雀通 App 已登录并接入云雀通网络。
2. 确认目标 Windows/Mac 的 WebRTC 服务端已安装、启动，访问令牌已设置。
3. 直接模式确认电脑 Larktun 在线；子网模式确认路由节点在线、子网已批准且权限允许。
4. 使用正确的目标 IP、端口、Token 连接，看到桌面并实际完成一次点击与输入。
5. 按需测试声音、剪贴板和显示器切换。
6. 在电脑旁完成首次配置后，切换手机到移动网络再连接一次，确认外出访问也能正常使用。

更多连接问题见 [常见问题处理](../troubleshooting/common-issues)，完整移动端能力见 [iOS 客户端功能介绍](../introduction/ios-app-overview)；Android 版的 WebRTC、平板布局和手机界面介绍见 [云雀通 Android App 大更新](/blog/larktun-android-webrtc-tablet-phone-ui)。
