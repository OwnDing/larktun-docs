# 云雀通 Larktun iOS 客户端功能介绍

云雀通 Larktun iOS App 面向 iPhone 与 iPad，目标不是只做“能连上”的组网工具，而是把常用远程访问能力直接做进 App：组网、网页访问、WebRTC 安全远控、远程桌面、SSH、SFTP、文件传输、设备发现与多窗口协作，都可以在一个入口完成。

对于移动办公、远程运维、家庭实验室、NAS 管理和 AI Coding 场景来说，这意味着你不必在多个 App 之间来回切换，也不需要先记住 IP、端口和设备名称再开始操作。

## 为什么 iOS 版更适合随身远程访问

- 不占用系统 VPN 权限，打开 App 就能进入云雀通网络
- 一站式集成 Web、WebRTC、RDP、SSH、SFTP 和文件传输
- 适配 iPad 多标签、标签撕离和外接屏，便于并行操作
- 既适合临时应急访问，也适合长时间远程工作与运维

## 核心能力

### 1. 不使用系统 VPN 权限，也能完成组网连接

云雀通 iOS App 支持在应用内部完成组网连接。你不需要占用系统级 VPN 通道，也不需要把整台 iPhone 或 iPad 的流量都切到私有网络。

这种方式特别适合以下场景：

- 手机或 iPad 已经连接公司 VPN，但你还想访问自己的私有网络设备
- 只希望云雀通 App 内的访问能力进入组网，而不是让所有 App 共用同一条隧道
- 想降低移动端授权门槛，让打开 App 即可访问成为默认体验

更底层的原理和适用边界，可以继续阅读：[无需 VPN 权限的 iOS 组网 App](../topics/ios-app-without-vpn-permission)。

### 2. 内置浏览器，随时访问组网内网页服务

App 内置浏览器，可以直接访问组网内的控制台、NAS 页面、路由器后台、可视化面板、Web 管理系统和 AI 服务 Web UI。

- 不需要复制地址到第三方浏览器
- 适合访问只能在内网打开的网页服务
- 在移动网络、Wi-Fi 和差旅场景下都能快速进入目标页面

### 3. 支持 WebRTC 点对点远程控制，安全远控更轻量

除了传统远程桌面方式，云雀通 iOS App 还支持基于 WebRTC 的点对点远程控制能力，适合更轻量、更低延迟的安全远控场景。

- 支持 WebRTC 点对点远控，优先建立更直接的访问链路
- 适合对远程控制时延和交互体验更敏感的场景
- 在不暴露公网端口的前提下完成安全远控
- 可作为移动端快速进入远程设备的高频入口

### 4. 内置 RDP，直接远程到设备或子网中的桌面主机

云雀通 iOS App 内置 RDP，能够直接远程到组网设备，也支持远程访问子网内提供 RDP 服务的 Windows 或 Linux 主机。

- 适合访问办公室电脑、云服务器桌面、实验环境和运维跳板机
- 可以把“发现设备”和“进入桌面”连成一条连续操作链路
- 在 iPad 上配合键盘、鼠标和外接屏，体验更接近随身控制台

### 5. 支持 SSH / SFTP，方便远程服务器运维与 AI Coding

对于研发、运维和 AI Coding 场景，iOS 客户端内置 SSH 与 SFTP 是非常高频的能力组合。

- SSH 可用于登录服务器、执行命令、查看日志、编辑配置
- SFTP 可用于上传下载文件、同步脚本、管理项目目录
- 适合连接云主机、家庭服务器、开发机、跳板机与实验节点
- 对 AI Coding 场景来说，可以更方便地连接远程代码环境、Agent 宿主机和工具链服务

### 6. 支持智能路由与智能发现，无需手记设备

云雀通 iOS App 支持智能路由与智能发现，能自动识别常见协议与网页入口，并支持对子网进行扫描，帮助你快速找到可以访问的设备与服务。

- 自动发现常见 Web、SSH、RDP 等入口
- 减少记忆 IP、端口和设备名的负担
- 对家庭网络、办公室子网和实验环境尤其友好
- 当设备数量增长时，仍然能保持清晰可用的访问入口

### 7. 支持收藏，常用 SSH / RDP / Web 服务一键直达

你可以把常用的 SSH、RDP、Web 等连接一键加入收藏。之后再次访问时，不需要重复查找设备或重新输入目标信息，直接从收藏栏进入即可。

- 适合固定使用的服务器、NAS、后台系统和开发环境
- 降低高频访问时的操作成本
- 让移动端也能形成稳定的“个人工作台”

### 8. 支持多标签同时显示 SSH、RDP、网页等会话

云雀通 iOS App 支持多标签同时打开不同类型的远程会话。

- 可以一边看 SSH 日志，一边开着 Web 控制台
- 可以同时保留多个 RDP、SSH 或浏览器会话
- 更适合排障、发布、巡检和多系统协同处理

### 9. 支持标签撕离，iPad 上可拆成独立窗口

在 iPad 上，标签支持撕离成独立窗口。这样你可以把一个 RDP 会话单独拉出，同时保留另一个 SSH 或网页会话继续工作。

- 更适合多任务并行
- 让 iPad 更接近桌面级远程工作方式
- 对运维、开发、测试和远程协助都很实用

### 10. 支持外接屏，把 iPad 变成随身控制台

云雀通 iOS App 支持外接显示器。连接外接屏后，可以把 RDP 全屏显示到外接屏上，提升远程桌面操作体验。

- iPad 本体可继续保留 SSH、SFTP 或浏览器辅助窗口
- 外接屏适合承载主要远程桌面会话
- 对移动办公、驻场支持和临时远程值守非常有帮助

### 11. 支持与组网设备互传文件

云雀通 iOS App 支持与组网设备进行文件收发。

- 可以把截图、文档、脚本和配置文件发送到目标设备
- 也可以把日志、导出文件或结果文件拉回本地
- 对移动排障、远程协作和 AI Coding 文件交换都很实用

## 一句话理解这款 iOS App

如果说传统组网工具解决的是“怎么连进去”，那么云雀通 iOS App 解决的是“连进去之后，怎么立刻开始工作”。

它把访问入口、WebRTC 远控、远程桌面、终端、文件、发现和多任务协作放进同一个 App，更适合移动办公与 iPad 生产力场景。

## 适合的使用场景

- 在 iPhone 上临时登录服务器处理故障
- 在 iPad 上同时打开 RDP、SSH 和浏览器完成远程运维
- 访问 NAS、路由器、家庭实验室和办公内网页面
- 使用外接屏把 iPad 变成远程桌面工作台
- 连接 AI Agent、代码环境和远程开发服务器
