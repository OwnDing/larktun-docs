# 使用 Tailscale 客户端登入云雀通

云雀通（Larktun）是基于 tailscale/headscale 深度开发的企业级网络互联平台。因此，原生的 Tailscale 客户端能够直接登入到云雀通的网络上。

如果您原先就使用过 Tailscale，您**不需要**安装我们云雀通专属的客户端。您可以直接使用现有的 Tailscale 客户端登入云雀通的网络，享受便捷的国内组网服务。

以下是具体的操作说明：

## 1. 注册并登入云雀通控制台

首先，请访问云雀通控制台完成账号注册并登入：
- 进入您的租户或工作空间。
- 确保您的账号状态正常，且有足够的设备接入配额。

## 2. 创建密钥 (Auth Key)

为了让设备安全地接入网络，您需要创建一个访问密钥：
1. 在控制台左侧导航栏中进入 **机器 (Nodes)** 页面。
2. 点击 **生成授权密钥**，为新设备生成一个专用的访问密钥。
3. **注意**：请妥善复制并保存此密钥，出于安全考虑，它只会完整显示一次。

## 3. 使用密钥登入

根据您的操作系统，在终端或命令行中执行相应的 Tailscale 登入命令。请将其中的 `<您的 Auth Key>` 替换为您在上一步中获取的密钥，并将 `--login-server` 设置为云雀通的服务地址。

> **提示：** 这里的 `--login-server` 参数需要指向云雀通的接入控制面（例如 `https://hs.larktun.com`，具体请以控制台页面中的引导提示为准）。

### Linux / macOS

打开终端（Terminal），执行以下命令：

```bash
tailscale up --login-server=https://hs.larktun.com --auth-key=<您的 Auth Key>
```

### Windows

如果您使用的是 Windows 系统，您可以以管理员身份打开命令提示符（CMD）或 PowerShell，执行相同的命令：

```cmd
tailscale up --login-server=https://hs.larktun.com --auth-key=<您的 Auth Key>
```

*(注意：在某些 Tailscale 客户端版本中，Windows 用户也可以通过按住 `Shift` 键右击托盘图标，进入偏好设置中直接修改 Login Server。)*

## 验证接入状态

完成上述登入命令后，您的设备就会自动连接到云雀通的网络中。您可以回到云雀通控制台的 **Nodes (设备)** 页面，刷新后即可查看到刚刚成功接入的设备。
