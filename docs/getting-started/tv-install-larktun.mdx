# 在 TV 电视上安装云雀通

云雀通（Larktun）的 Android App 同样可以安装在 Android TV 电视、电视盒子和投影仪上。安装并登入后，电视会作为一个节点加入你的云雀通网络，你可以直接在客厅的大屏上远程控制家里或公司的电脑，也可以打开 NAS 后台、SSH 终端和内网 Web 服务。

电视端使用的是**云雀通 NoVPN 版 APK**。它在 App 内完成组网，不申请系统 VPN 权限，因此不会占用电视上的 VPN 入口，也不影响电视本身的网络设置。

:::tip[整体流程]
开启电视的开发者模式 → 下载 NoVPN 版 APK → 安装 → 登入 App → 连接蓝牙鼠标 → 远程到电脑。
:::

## 开始前准备

- 一台 Android TV 电视、电视盒子或智能投影仪（Android 系统），并已连接网络。
- 注册并登入 [云雀通控制台](https://larktun.com/auth/login)。
- 一个蓝牙鼠标（强烈建议）。遥控器可以完成安装和登入，但远程桌面阶段需要指针操作。
- 想远程的那台电脑已经安装并登入云雀通，且处于在线状态。

:::note[关于 APK 架构]
云雀通 NoVPN 版 APK 同时包含 **arm64（arm64-v8a）** 和 **armv7（armeabi-v7a）** 两种架构，绝大多数电视和电视盒子都可以直接安装同一个安装包，不需要区分机型下载。
:::

## 1. 打开电视的开发者模式

电视系统默认不允许安装外部应用，需要先打开开发者模式并允许未知来源安装。

以原生 Android TV 为例：

1. 进入电视的 **设置 > 系统 > 关于**（部分系统为 **设置 > 关于本机**）。
2. 找到 **版本号**（Build number），用遥控器连续点击 7 次。
3. 屏幕提示 **您现在已是开发者** 后，返回上一级菜单，即可看到 **开发者选项**。
4. 回到 **设置 > 应用 > 特殊应用权限 > 安装未知应用**（部分系统为 **安全和限制 > 未知来源**），把用于安装的应用（文件管理器或浏览器）设为允许。

不同品牌的电视菜单名称略有差异，例如小米、TCL、创维、索尼、Nvidia Shield 的路径不完全相同，但都遵循同一个逻辑：**连续点击版本号开启开发者模式，再为安装来源单独授权**。

:::warning
未知来源安装权限建议只授予你实际使用的那一个应用（例如系统自带的文件管理器）。安装完成后可以关闭该权限，不影响已安装的 App 运行。
:::

## 2. 下载云雀通 NoVPN 版 APK

前往 [云雀通下载页](https://larktun.com/download)，选择 **Android NoVPN 版 APK**，文件名为 `larktun-novpn-latest.apk`。可以按电视的实际情况选择下面任意一种方式：

- **电视浏览器直接下载**：在电视自带浏览器中打开下载页，下载后用文件管理器打开安装包。这是最省事的方式。
- **U 盘拷贝**：先在电脑上下载 APK，拷贝到 U 盘，插到电视上用文件管理器安装。适合电视没有可用浏览器的情况。
- **局域网传输**：用电视上的文件管理器访问局域网共享目录或 NAS，直接读取 APK。
- **adb 安装**：如果你已经在开发者选项中打开了 **USB 调试** 或 **网络调试**，可以在电脑上执行：

  ```bash
  adb connect <电视局域网 IP>:5555
  adb install larktun-novpn-latest.apk
  ```

## 3. 安装 APK

用文件管理器打开下载好的 APK，按提示确认安装。

- 如果提示 **禁止安装未知来源应用**，回到第 1 步为当前文件管理器或浏览器授予安装权限。
- 如果提示 **解析软件包时出现问题**，通常是安装包没有下载完整，重新下载即可。
- 安装完成后，云雀通会出现在电视的应用列表中。部分电视系统不会把第三方应用放到首页，需要进入 **设置 > 应用** 或全部应用列表中查看，并手动添加到首页。

## 4. 登入云雀通

打开云雀通 App，选择一种方式登入：

- **账号登入**：使用云雀通账号和密码登入，适合日常使用。
- **Auth Key 登入**：在控制台的 **Nodes（设备）** 页面生成一枚 Auth Key，在 App 中填入。电视上输入长字符串比较麻烦，建议配合蓝牙鼠标或电视的手机遥控 App 完成粘贴。
- **第三方登入**：如果你使用的是 Tailscale 或自建 Headscale，可以在高级设置中填入对应的 Auth Key 与控制服务器地址，具体参考 [iOS App 登入第三方 Tailscale / Headscale](./ios-third-party-login)，Android 端填写方式一致。

登入成功后，App 会拉取你在这个网络中有权限看到的设备列表，电视也会出现在控制台的 **Nodes（设备）** 页面中。

## 5. 配一台蓝牙鼠标

电视遥控器只有方向键和确认键，用来浏览设备列表没问题，但进入远程桌面后就需要一个真正的指针。**建议为电视配一个蓝牙鼠标**，这是电视端体验好坏的关键。

在电视的 **设置 > 遥控器与配件 > 添加配件** 中，让鼠标进入配对模式并完成连接。

体验建议：

- **蓝牙鼠标 + 遥控器**：最低成本组合，能满足大部分远程操作。
- **蓝牙键鼠套装**：需要在电脑上打字（写代码、回消息、填表单）时更从容。
- **带触控板的飞鼠遥控器**：偶尔用一下也可以，长时间操作不如鼠标顺手。

## 6. 在电视上远程到电脑

确认目标电脑已经打开远程桌面（Windows 在 **设置 > 系统 > 远程桌面** 中开启），然后在电视上的云雀通 App 中：

1. 在设备列表中找到那台电脑，确认状态为在线。
2. 选择 **RDP** 远程桌面入口。
3. 填入电脑的用户名与密码（首次连接后可以保存）。
4. 进入远程桌面，切换到全屏，用蓝牙鼠标正常操作。

连接建立在云雀通网络内部，电脑不需要把 3389 端口映射到公网，也不需要 DDNS。

除了远程桌面，电视上的云雀通 App 同样可以打开内网 Web 服务（NAS 后台、Home Assistant、Jellyfin 等）、SSH 终端和 SFTP 文件管理，具体能力可以参考 [云雀通 Android App 全面升级](/blog/larktun-android-app-smart-discovery-webview-free)。

## 常见问题

- **找不到开发者选项**：确认是在 **关于** 页面连续点击的 **版本号**，而不是型号或系统版本；部分系统需要点击 7 次以上。
- **安装被系统拦截**：电视厂商的系统可能有额外的应用安装限制，需要在 **安全** 或 **应用管理** 中单独放行。
- **安装包无法解析**：重新下载 APK，并确认下载过程中没有中断。
- **App 装好了但首页看不到**：进入全部应用列表打开，或在电视首页的自定义频道中把云雀通添加进来。
- **登入后看不到电脑**：确认电脑端的云雀通在线，并检查 ACL 是否允许电视这台设备访问目标电脑。
- **远程桌面连不上**：确认目标电脑已开启远程桌面服务、账号密码正确，且 ACL 放行了 RDP 端口（默认 3389）。Windows 家庭版默认不带远程桌面服务端。
- **画面卡顿**：优先让电视使用有线网络或 5GHz Wi-Fi；如果跨地域访问，可以在控制台的 **Derper** 页面切换到更近的中继节点。
- **遥控器点不到远程桌面里的按钮**：这是正常现象，远程桌面需要指针输入，请连接蓝牙鼠标。
