# 使用 RustDesk 进行 IP 远程操作说明

RustDesk 是一款开源免费的跨平台远程桌面软件，同时支持 **Windows（包含家庭版与专业版）、macOS 和 Linux**，并且连入时保留被控电脑的当前桌面现场。

默认情况下，RustDesk 需要通过公共 ID / 中继服务器建立连接（高峰期容易限速或连不上），或者需要你自行租用云服务器自建中继服务（hbbs / hbbr）。但当你把 **云雀通（Larktun）** 与 RustDesk 的 **「允许 IP 直接访问（Direct IP Access）」** 功能结合起来时，体验会彻底简化：

- **不用自建 RustDesk 中继服务器**：不需要租公网服务器、部署 hbbs / hbbr、配域名或折腾 Key。
- **绕开 RustDesk 公共服务器**：哪怕软件底部提示“未就绪 / 无法连接公共服务器”，通过云雀通私有 IP 照样秒连。
- **更快更稳**：优先通过云雀通 WireGuard 建立端到端 P2P 直连，NAT 受限时自动走云雀通中继节点（支持免费、专用或自建中继）。
- **零公网端口暴露**：无需在路由器上映射 `21118` 端口，仅云雀通私有网络内授权设备可访问。
- **支持直接组网与子网路由**：既可以用被控机的 `100.x.x.x` 私有 IP 连接，也可以通过子网路由直接连内网局域网 IP（如 `192.168.6.10`）。

![云雀通 + RustDesk IP 远程直连架构](/img/docs/remote/rustdesk-architecture.svg)

## 1. 使用前先确认适用场景与组件

在开始配置前，请先确认各端需要安装的软件：

| 设备角色 | 操作系统 | 需安装的程序 | 说明 |
| --- | --- | --- | --- |
| 被控端（直接组网） | Windows / macOS / Linux | **Larktun 桌面客户端** + **RustDesk** | 开启 RustDesk「允许 IP 直接访问（`21118`）」与固定密码 |
| 被控端（子网模式） | 局域网内 Windows / macOS / Linux | 仅需安装 **RustDesk**（可不装 Larktun） | 由同局域网的一台云雀通子网路由节点转发流量 |
| 控制端（电脑） | Windows / macOS / Linux | **Larktun 桌面客户端** + **RustDesk** | 电脑端 Larktun 创建系统虚拟网卡，RustDesk 可直接填 IP 连接 |
| 控制端（手机 / 平板） | iPhone / iPad / Android | 见第 6 节说明 | 手机使用第三方 RustDesk 需系统 VPN 模式；免 VPN 推荐直接用云雀通 App 内置 WebRTC / RDP |

- 云雀通客户端可前往 [Larktun 下载页](https://larktun.com/download) 获取。
- RustDesk 客户端请从 [RustDesk 官网或 GitHub Releases](https://rustdesk.com) 下载官方安装包。

## 2. 第一步：先完成云雀通组网并获取目标 IP

1. 在**被控电脑**和**控制端电脑**上分别安装并登录 **Larktun 桌面客户端（Larktun IPN）**，使用同一个云雀通账号（或同租户内有权限互访的账号）。安装登录步骤见 [电脑客户端操作](./desktop-client-operations)。
2. 建议在被控电脑的 Larktun 客户端 **设置** 中勾选 **开机自启动** 和 **最小化托盘**，保证电脑重启后自动重新上线。
3. 确认两端顶部都显示 **已连接**，在控制端电脑的设备列表中找到被控电脑，点击右侧菜单选择 **复制 IP 地址**（例如 `100.64.0.10`），并点击 **Ping** 确认网络已通：

![在云雀通电脑客户端复制目标设备 IP 或执行 Ping 测试](/img/desktop-client/fig3-6-device-actions.webp)

同账号下的设备登录云雀通后默认即可互通，无需额外配置 ACL 规则（仅当你手动自定义收紧过访问策略时，再确认未拦截 `21118` 端口即可）。

## 3. 第二步：在被控端电脑配置 RustDesk

请在**需要被远程控制的电脑**上完成以下配置。

![被控端 RustDesk 关键配置：解锁安全设置、允许 IP 直接访问并设置固定密码](/img/docs/remote/rustdesk-host-settings.svg)

### 3.1 完整安装为系统服务（Windows 必看）

如果你下载的是 Windows 版 RustDesk，首次打开时如果顶部或左下角提示 **安装**，请务必点击 **安装** 将其安装为 Windows 系统服务（开机自启）。

:::important[为什么建议安装为系统服务，而不是只运行绿色版？]
仅以普通用户运行免安装版时：
1. 被控电脑遇到 **UAC 管理员授权弹窗** 或进入 **Windows 锁屏 / 登录界面** 后，远程鼠标将无法点击。
2. 电脑重启后不会自动后台启动 RustDesk。

安装为系统服务后，才能实现真正的无人值守远控。
:::

### 3.2 开启「允许 IP 直接访问」与固定密码

1. 打开被控端 RustDesk，点击 ID 旁边的菜单图标（三个点或齿轮图标）进入 **设置**。
2. 在左侧选择 **安全** 标签页，点击顶部的 **解锁安全设置**，按系统提示通过管理员授权。
3. 在 **安全** 分组下，勾选 **允许 IP 直接访问**（部分版本显示为 **启用直接 IP 访问**）。
4. 确认下方 **直接 IP 访问端口** 为默认值 **`21118`**（如需改用其他端口，记住新端口号并在本机防火墙中同步放行）。
5. 在同一页面的 **密码** 区域：
   - 点击 **设置固定密码**，设置一个**高强度密码**（建议至少 10 位，包含大小写字母和数字）。
   - 将密码验证模式选为 **使用固定密码**（或 **同时使用两种密码**），这样无人值守时无需对方手动点击「接受」即可直接输入密码连入。
6. **网络设置保持默认即可**：不需要进入「网络」页填写任何 ID 服务器、中继服务器或 Key，留空即可。

### 3.3 检查系统防火墙、权限与电源设置

- **Windows 防火墙**：
  首次开启 IP 直接访问时，若弹出 Windows 安全中心提示，请允许 RustDesk 通信。如果后续仍连不上，可以以管理员身份打开 PowerShell，放行仅来自云雀通网段（`100.64.0.0/10`）的 `TCP 21118` 入站流量：

  ```powershell
  # 检查 RustDesk 是否正在监听 21118 端口
  Get-NetTCPConnection -LocalPort 21118 -State Listen

  # 添加仅允许云雀通私有网段访问 TCP 21118 的入站规则
  New-NetFirewallRule -DisplayName "Larktun RustDesk Direct IP (TCP 21118)" -Direction Inbound -Protocol TCP -LocalPort 21118 -RemoteAddress 100.64.0.0/10 -Action Allow
  ```

- **macOS 权限（如被控端是 Mac）**：
  前往 **系统设置 → 隐私与安全性**，为 RustDesk 勾选开启 **屏幕录制** 和 **辅助功能**（如需远程传文件或无障碍操作，按提示授予对应权限），授权后重启 RustDesk。若只开屏幕录制未开辅助功能，会出现“能看到画面但无法点击操作”。
- **Linux 提示（如被控端是 Linux 桌面）**：
  建议使用 X11 会话获得最稳定的无人值守体验；若开启了 `ufw` 或 `firewalld`，请放行来自云雀通接口或网段的 `TCP 21118`。
- **防止电脑休眠**：
  在系统电源设置中将接通电源时的自动睡眠改为 **从不**，避免外出后电脑休眠离线。

:::warning[安全边界提醒]
开启「允许 IP 直接访问」意味着本机直接监听 `TCP 21118`。**请务必设置强固定密码**，仅在云雀通私有网络内访问，**严禁在公网路由器上做 `21118` 端口映射**。
:::

## 4. 第三步：在控制端通过 IP 发起连接

在控制端电脑确认 Larktun 桌面客户端处于 **已连接** 状态后，打开 RustDesk：

![控制端 RustDesk 输入云雀通 IP 发起远程连接示意](/img/docs/remote/rustdesk-connect-ip.svg)

1. 在主界面顶部的 **控制远程桌面** 输入框中，直接输入被控电脑的云雀通私有 IP：
   - 默认端口 `21118`：直接输入 `100.64.0.10`
   - 若修改了直连端口（例如 `21188`）：输入 `100.64.0.10:21188`
   - 若已配置云雀通 MagicDNS：也可以输入目标主机名
2. 点击右侧连接箭头（或按回车键）。
3. 在弹出的密码输入框中输入被控端设置的 **固定密码**。在个人可信设备上可勾选 **记住密码**，以后双击「最近会话」或「收藏」卡片即可一键直连。
4. 连入桌面后，可以通过顶部工具栏调整：
   - **画质模式**：在「好画质 / 平衡 / 优化反应时间（流畅）」之间切换；跨网段带宽紧张时优先选「平衡」或「优化反应时间」。
   - **显示与音频**：支持多显示器切换、系统声音传输和双向剪贴板同步。
   - **文件传输**：在主界面点击已保存设备卡片右下角菜单，选择 **传输文件**，即可直接通过云雀通私有网络高速双向传文件。

:::tip[底部显示「未就绪」不影响 IP 直连！]
打开 RustDesk 时，如果窗口底部状态栏提示 **「未就绪，请检查网络连接」**，这只是说明它当前没有连上 RustDesk 官方公共 ID 服务器。**IP 直接访问完全不经过公共服务器**——只要你的云雀通网络正常且能 Ping 通目标 IP，直接输入 `100.64.0.10` 依然可以顺畅连接。
:::

## 5. 进阶：通过子网路由连接内网多台 RustDesk 电脑

如果办公室或实验室局域网（例如 `192.168.6.0/24`）里有多台电脑，你不需要给每一台都装云雀通客户端：

1. 在该局域网的一台路由器、Linux 主机或常开电脑上宣告 `192.168.6.0/24` 子网路由，并在云雀通控制台 **路由（Routers）** 页面批准该网段（详见 [批准子网路由](./approve-subnet-routes)）。
2. 在控制端电脑上确认接受了子网路由（CLI 客户端可执行 `sudo larktun set --accept-routes`）。
3. 在每台需要被控的内网电脑（如 `192.168.6.10`）上安装 RustDesk，按第 3 节开启 **允许 IP 直接访问** 并设置 **固定密码**，确保其本机防火墙允许来自局域网路由节点的 `TCP 21118`。
4. 在控制端 RustDesk 输入框直接填写被控电脑的**局域网 IP**（如 `192.168.6.10`），输入固定密码即可连接。

![在云雀通控制台路由页面批准内网子网路由](/img/docs/quickstart/routes/routers.webp)

:::note[避免内网 IP 变动]
子网模式下如果被控电脑通过 DHCP 获取的局域网 IP 变化了，需要更新 RustDesk 中填写的地址。建议在办公室路由器中为常用被控电脑绑定静态 DHCP IP。
:::

## 6. 手机 / 平板使用 RustDesk 的重要说明

很多用户会在手机上同时装了 **云雀通手机 App** 和 **RustDesk 手机 App**，却发现 RustDesk 里填 `100.64.0.10` 连不上。原因在于移动端与电脑端的网络边界不同：

![手机平板使用 RustDesk 时的网络边界对比：App 内组网 vs 系统 VPN](/img/docs/remote/rustdesk-mobile-network-boundary.svg)

- **云雀通手机 App（iOS / Android NoVPN 版）**：采用 **App 内 `tsnet` 组网**，不占用系统 VPN 权限，因此只有云雀通 App 内部的功能（内置 WebRTC 远控、内置 RDP、SSH、SFTP、内置浏览器）能访问 `100.x.x.x`；手机上其他独立的第三方 App（包括 RustDesk App）无法路由到云雀通虚拟 IP。
- **方案一（推荐，手机免 VPN 原生远控）**：
  - 想保留电脑当前桌面现场、支持 Windows 家庭版和 macOS → 直接使用云雀通 App 内置的 [WebRTC 远程控制](./webrtc-remote-control)。
  - 被控端是 Windows 专业版/企业版 → 直接使用云雀通 App 内置的 [微软 RDP 远程桌面](./rdp-remote-desktop)。
- **方案二（确实需要在手机上用 RustDesk App）**：
  - 在手机上安装官方 **Tailscale App**，使用云雀通控制台生成的 Auth Key 和控制服务器 `https://hs.larktun.com` 登入并启用系统级 VPN（完整图文见 [在 iPhone 和 iPad 上使用 Tailscale 登入云雀通](./ios-tailscale-login-larktun) 与 [使用 Tailscale 客户端登入](./tailscale-client-login)）。
  - 系统 VPN 连通后，打开手机上的 RustDesk App，直接输入 `100.64.0.10`（或子网 IP `192.168.6.10`）+ 固定密码即可远控。

## 7. 三种远程方式快速对比

| 对比维度 | RustDesk IP 远程（本文） | 微软自带 RDP | 云雀通 WebRTC 远控 |
| --- | --- | --- | --- |
| **被控系统** | Windows（含家庭版）、macOS、Linux | Windows 专业版/企业版/Server、Linux（xrdp） | Windows（含家庭版）、macOS |
| **是否需要中继服务器** | 无需自建 hbbs/hbbr，复用云雀通传输层 | 无需公网中继，复用云雀通传输层 | 无需公网 TURN，复用云雀通传输层 |
| **本地桌面状态** | 共享当前桌面，不锁本机屏 | 连入时锁本机屏，独占会话 | 共享当前桌面，支持多设备观看与接管控制 |
| **默认私有端口** | TCP `21118` | TCP `3389` | TCP `8771`（子网含 `3478`） |
| **电脑到电脑体验** | 极佳（跨平台互控、文件传输、多屏） | 极佳（原生系统体验、清晰文字） | 目前控制端主打手机与平板 App |
| **手机到电脑体验** | 需官方 Tailscale App 系统 VPN | 云雀通 App 原生内置，免 VPN | 云雀通 App 原生内置，免 VPN |

## 8. 常见问题排查

| 现象 | 原因与排查方法 |
| --- | --- |
| 输入 `100.64.0.10` 提示连接超时 / 被拒绝 | ① 先在云雀通客户端对目标 IP 执行 **Ping** 确认在线；② 确认被控端 RustDesk 已勾选 **允许 IP 直接访问**；③ 检查目标电脑防火墙是否放行 `TCP 21118`（如手动收紧过自定义 ACL 也需检查）；④ 若修改了端口，确认填写格式为 `IP:端口` |
| 手机上 RustDesk 连不上 `100.64.0.10`，但云雀通 App 里能 Ping 通 | 云雀通手机 App 是 NoVPN App 内组网，第三方 RustDesk App 无法访问 `100.x.x.x`。请改用云雀通内置 WebRTC / RDP，或按第 6 节用官方 Tailscale App 接入云雀通建立系统 VPN |
| 提示需要对方同意，无人值守连不进去 | 回到被控端 RustDesk **设置 → 安全**，设置 **固定密码**，并将验证模式设为 **使用固定密码**（或同时使用两种密码） |
| 连上 Windows 后，管理员弹窗（UAC）或锁屏界面点不了 | 被控端运行的是免安装绿色版。请在被控端 RustDesk 主界面点击 **安装**，将其安装为 Windows 系统服务后重启 |
| 连上 macOS 后黑屏或只能看不能点 | 在 Mac **系统设置 → 隐私与安全性** 中同时为 RustDesk 开启 **屏幕录制** 和 **辅助功能** 权限，然后完全退出并重开 RustDesk |
| RustDesk 底部一直显示「未就绪」 | 正常现象，代表未连接官方公共中继服务器；只要云雀通在线，直接输入 `100.x.x.x` 即可发起 IP 直连 |
| 跨地区访问画面延迟较高 | ① 在云雀通客户端点 **Ping** 查看当前是直连还是中继；② 可在控制台 **Derper** 切换到更近的中继或专用中继；③ 在 RustDesk 顶部工具栏切到「平衡」或「优化反应时间」 |
| 子网内目标机连不上 | 确认控制台已批准子网路由、控制端电脑接受了路由，目标机防火墙允许来自局域网路由节点的 `TCP 21118`（如自定义过 ACL 也请检查是否允许访问该子网） |

## 9. 首次配置验收清单

1. 两端电脑均已登录云雀通且在线，控制端 Ping 被控端私有 IP 成功（或子网路由已批准并可达）。
2. 被控端 RustDesk 已安装为系统服务（Windows）、已开启 **允许 IP 直接访问（`21118`）**、已设置强 **固定密码**，且 Mac 已授予屏幕录制与辅助功能权限。
3. 被控端本机防火墙已放行私有网段的 `TCP 21118`，且公网路由器**未映射**任何 RustDesk 端口。
4. 在控制端 RustDesk 输入 `100.x.x.x`（或子网 IP）+ 固定密码成功看到桌面，实测鼠标点击、键盘输入与文件传输正常。
5. 切换控制端到手机热点或外部网络再次测试一次，确认异地访问同样顺畅。
