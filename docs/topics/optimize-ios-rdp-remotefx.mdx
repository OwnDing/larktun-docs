# iOS 远程桌面画质优化：启用 RemoteFX

云雀通 iOS App 内置 RDP 远程桌面，通过 `tsnet` 直接访问你私有网络中的 Windows 设备，无需公网端口。图形编码会按下面的顺序自动协商：

1. **H.264（AVC444）**：默认模式。画质和带宽表现最好，绝大多数 Windows 10 / 11 无需任何配置即可使用。
2. **经典 RemoteFX**：回落模式。当 H.264 不可用时自动启用，文字清晰、带宽占用低，但需要在 Windows 上打开一项组策略。
3. **原始位图**：兜底模式。任何服务器都可用，画面正确但清晰度和流量表现一般。

如果你的连接一直工作在默认的 H.264 模式，不需要做任何事情。本文只在以下场景有用：

- 你在连接设置的「高级设置」里选择了位图模式，或关闭了 H.264（AVC444）开关；
- 远端 Windows 不支持 H.264 编码（例如部分精简版系统、较老的服务器版本）；
- 你希望回落模式的画质尽可能接近主模式。

## 在 Windows 上启用 RemoteFX

Windows 默认不对这类连接启用经典 RemoteFX。在**被连接的 Windows 电脑**上按以下步骤开启：

1. 按 `Win + R`，输入 `gpedit.msc`，回车打开「本地组策略编辑器」。
2. 依次展开：计算机配置 → 管理模板 → Windows 组件 → 远程桌面服务 → 远程桌面会话主机 → 远程会话环境 → RemoteFX for Windows Server 2008 R2。
3. 双击「配置 RemoteFX」，选择「已启用」，点击确定。
4. 打开命令提示符，执行 `gpupdate /force` 使策略生效。
5. **注销**当前的远程会话（不是断开连接），然后从云雀通 App 重新连接。

重新连接后，位图模式下的文字应明显更锐利，滚动和窗口拖动也更流畅。

## 家庭版没有组策略编辑器？

Windows 家庭版（Home）没有 `gpedit.msc`，可以用注册表达到同样效果。以管理员身份打开命令提示符，执行：

```
reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows NT\Terminal Services" /v fEnableVirtualizedGraphics /t REG_DWORD /d 1 /f
```

然后注销远程会话并重新连接。若要撤销，把 `/d 1` 改为 `/d 0` 再执行一次，或删除该值。

## 仍未生效？

- 确认修改的是**被连接的电脑**（RDP 服务端），不是发起连接的设备。
- 在同一策略目录下，把「为 Windows Server 2008 R2 SP1 设计的 RemoteFX 客户端启用 RemoteFX 编码」也设为「已启用」，再执行 `gpupdate /force` 并注销重连。
- 确认连接设置中的色彩深度为 32 位（默认值）。16 位色深不会启用 RemoteFX。
- 部分企业环境的域策略可能覆盖本地设置，需联系管理员。

## 常见问题

**这个设置有安全风险吗？**
没有。它只改变远程桌面的图形编码方式，不影响认证、加密或网络暴露面。连接本身仍然走云雀通的私有网络。

**Linux（xrdp）需要配置吗？**
一般不需要。主流发行版打包的 xrdp 自带 RemoteFX 编码，云雀通 App 连接时会自动协商。

**默认的 H.264 模式需要这个设置吗？**
不需要。该设置只影响回落模式；只要 H.264 协商成功，App 始终优先使用 H.264。
