# Open Source Links

Larktun is built on top of open-source zero-trust networking ideas and publishes key client repositories, Headscale SaaS architecture demos, benchmarking scripts, and documentation sources publicly so developers can audit, learn from, and contribute to the ecosystem.

## Public Repositories

| Project | Repository | What It Covers |
|---|---|---|
| **Android Client (Meshyra)** | [OwnDing/meshyra-android](https://github.com/OwnDing/meshyra-android) | Full Android client source code (active release branch: `release-branch/1.86`). |
| **Android NoVPN Client** | [OwnDing/larktun-android-open](https://github.com/OwnDing/larktun-android-open) | In-app networking Android client built with `tsnet`, requiring no system VPN permission. |
| **Documentation Site** | [OwnDing/larktun-docs](https://github.com/OwnDing/larktun-docs) | Bilingual (Chinese & English) Docusaurus documentation, guides, and engineering blog. |
| **Architecture Simulator** | [OwnDing/larktun-architecture-demo](https://github.com/OwnDing/larktun-architecture-demo) | Interactive visualization demonstrating login, Headscale control plane, direct P2P, and DERP relay flows. |
| **Headscale SaaS Demo** | [OwnDing/headscale-saas](https://github.com/OwnDing/headscale-saas) | Reference architecture for `cluster_id` sharding, multi-tenant isolation, and scalable Headscale deployments. |
| **Headscale Stress-Test Scripts** | [OwnDing/headscale-test-scripts](https://github.com/OwnDing/headscale-test-scripts) | Containerized 200+ client bootstrap, reconnect churn, and TCP/UDP traffic sampling harness. |
| **Headscale Java Demo** | [OwnDing/headscale-java](https://github.com/OwnDing/headscale-java) | Java integration demo for interacting with Headscale control-plane APIs. |

## Roadmap for Additional Open-Source Releases

Based on maintenance capacity and stabilization milestones, we plan to continue evaluating additional components for open-source release, including:

- Core `larktun` SaaS control-plane modules and multi-tenant clustering components
- `larktun-ipn` networking core utilities
- `larktun` Windows packaging tooling
- Additional client components across desktop and mobile platforms

## How to Get Involved

- **Spot a documentation issue or want to improve a guide?** Open an issue or pull request directly in [OwnDing/larktun-docs](https://github.com/OwnDing/larktun-docs).
- **Benchmarking your own Headscale deployment?** Start with [OwnDing/headscale-test-scripts](https://github.com/OwnDing/headscale-test-scripts) and read [Stress Testing Headscale at 200+ Concurrent Clients](/blog/headscale-stress-test).
- **Exploring multi-tenant Headscale architecture?** Read [Headscale Multi-Tenant Isolation](/blog/headscale-multi-tenant-isolation) and [Headscale Cluster Architecture](/blog/headscale-cluster-infinite-scale).
