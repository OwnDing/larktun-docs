在 Android 手机上访问自己的服务器、NAS、软路由或 Windows 电脑，过去常常要准备一整套工具：先连上组网，再找浏览器打开后台，换到 SSH 客户端处理命令，最后还得装一个 RDP 客户端远程桌面。网络虽然通了，真正做事时却一直在 App 之间来回切换。

## 这不是多装几个功能，而是把访问链路变短

传统流程的起点是地址：你得先记住目标设备的 IP、端口和协议，然后再决定用哪个 App 打开。

云雀通现在把起点换成了服务。连接自己的云雀通网络后，App 可以发现设备上的 Web、SSH、SFTP 和 RDP 服务，并把它们变成可以直接点击的入口。发现、连接和使用都在一个 App 里完成，不需要先翻通讯录，也不必在多个工具之间反复切换。

这对家庭网络、个人实验室和小团队尤其有用。NAS 后台、OpenWrt 管理页、Home Assistant、Grafana、开发服务器、Windows 工作站，过去是一串散落的地址；现在，它们更像 Android 手机上的一组私有应用。

## 智能发现：让网络自己告诉你有什么

云雀通 Android App 现在支持**智能发现**。

开始扫描后，App 会探测云雀通网络里的常见服务，识别 Web 页面、SSH、SFTP 和 RDP，并根据页面标题、服务响应和协议特征整理结果。发现服务后，可以直接打开网页、进入 SSH 终端、管理 SFTP 文件或连接 RDP 远程桌面，也可以一键收藏常用入口。

这套体验省掉了最容易劝退新用户的一步：配置。

你不必先研究“这个服务用了哪个端口”，也不必手动建立一排连接配置。打开智能发现，等网络把结果交给你，再点击需要的服务即可。对于通过子网路由访问的网段，扫描前仍会要求用户确认；发现结果保存在本机，边界清楚，也避免无意扫描不需要的网络。

## WebView 史诗级加强：ComfyUI 终于可以认真用了

很多私有服务最终都通过 Web 提供界面。今天的 Web 应用又远不只是几张静态页面：它们会使用 WebSocket、流式响应、文件上传、前端生成文件和全屏画布。一个只能“勉强打开网页”的 WebView，面对 ComfyUI、Home Assistant、Grafana、NAS 控制台时远远不够。

所以这次 Android 版的 WebView 不是小修小补，而是一次完整升级。

### 支持 ComfyUI 与复杂内网 Web 应用

云雀通内置浏览器已经针对 ComfyUI 这类大型单页应用做了增强。页面资源、实时进度、工作流交互、图片上传与结果下载，都可以继续通过 App 内的云雀通网络完成。你可以在外面拿出 Android 手机或平板，直接打开家里工作站上的 ComfyUI，而不必把它暴露到公网。

同样的能力也适用于 NAS 后台、Home Assistant、Grafana、Jellyfin、路由器管理页和各类自托管服务。

### 多标签：同时保留多个工作现场

内置浏览器现在支持多标签。你可以把 ComfyUI、NAS、监控面板和开发环境分别留在不同标签中，需要时快速切换，不再因为退出一个页面就丢掉刚才的工作现场。

网页里的新窗口也能进入新标签，常用页面可以收藏。Android 手机上是更接近现代浏览器的标签切换体验，在大屏平板上也更适合连续工作。

### 全屏：不只是视频，也包括真正的沉浸式操作

新版同时支持网页和视频使用的 HTML5 全屏，以及隐藏浏览器工具栏的沉浸式浏览。

看 Jellyfin 视频、打开监控画面、查看 Grafana 大屏，或放大 ComfyUI 画布时，内容都能真正占满屏幕。需要横屏时也可以快速旋转，不再被地址栏和系统界面挤占宝贵空间。

### 下载：从“点一下没反应”变成完整下载体验

下载也被重新做了一遍。普通 HTTP/HTTPS 文件、页面生成的 `blob:` 文件和 `data:` 文件都能处理，这意味着 ComfyUI 导出的图片、Grafana 导出的 CSV、NAS 在线打包的文件，不会再卡在“浏览器里能看到，手机里拿不到”。

下载任务可以在后台继续，下载中心会展示进度，并提供打开、分享、重试、取消和清理等操作。关闭发起下载的网页，也不会顺手把任务一起掐断。

除此之外，文件上传、桌面模式、自签名证书、网页权限、新窗口、页内查找等内网浏览常见需求也一并得到补强。现在的 WebView 不再只是设备列表旁边的一个附属入口，而是可以真正承担工作的内置浏览器。

## SSH 优化：手机终端也应该顺手

SSH 的价值从来不只是“能连上”。真正影响体验的是，连上之后能不能稳定输入、快速找回命令、方便处理文件。

新版 SSH 工作台继续优化了终端输入、滚动、文本选择和常用快捷键；支持密码与私钥登录，私钥既可以粘贴，也可以直接从 Android 文件选择器导入。命令历史可以查看和搜索，终端输出可以复制或保存，常用操作还能通过快捷指令减少手机上的重复输入。

终端与 SFTP 文件管理也放在同一个工作台里。执行命令后需要下载日志，或修改配置前先上传一个文件，不必退出 SSH 再寻找另一个 SFTP 工具。

这是一种更贴近真实维护流程的体验：不是把桌面终端缩小塞进手机，而是针对触屏、软键盘和移动场景重新整理操作路径。

## RDP 优化：更清晰，也更兼容

RDP 远程桌面也同步完成了图形链路优化。

在服务端支持时，云雀通可以使用 EGFX 与 H.264/AVC444 获得更清晰、更高效的远程画面；当目标环境不支持相应能力时，则自动回退到更兼容的经典图形模式，避免黑块、拖影和残留画面。Android 端的解码与首屏呈现也得到优化。

除了画面，远端音频、剪贴板和键鼠输入等工作场景需要的能力也集中在同一个 RDP 工作台中。临时回到 Windows 电脑处理桌面软件，Android 手机和平板都能成为随身入口。
